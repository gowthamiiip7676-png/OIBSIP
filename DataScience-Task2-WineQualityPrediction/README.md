Wine Quality Prediction

Project Overview

This project uses Machine Learning classification algorithms to predict wine quality based on its physicochemical properties.

Dataset

Wine Quality Red Dataset from the UCI Machine Learning Repository.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

Machine Learning Models

1. Random Forest Classifier
2. SGD Classifier
3. Support Vector Classifier (SVC)

Project Steps

- Data loading and preprocessing
- Exploratory Data Analysis
- Quality category classification
- Feature scaling and train-test splitting
- Model training and evaluation
- Confusion matrix visualization
- Feature importance analysis
- Model comparison

Conclusion

The three classification models were trained and evaluated using accuracy and macro F1-score. The model with the best macro F1-score was selected as the most suitable model.
