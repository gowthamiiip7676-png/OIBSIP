Iris Flower Classification

Project Overview

This project uses Machine Learning to classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

Objective

To build machine learning models that predict the species of an Iris flower using its physical measurements.

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Dataset

The built-in Iris dataset from Scikit-learn was used.

It contains 150 samples and 4 features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Project Steps

1. Imported the required libraries.
2. Loaded the Iris dataset.
3. Performed Exploratory Data Analysis (EDA).
4. Created pairplots and boxplots.
5. Selected important features.
6. Split the dataset into training and testing data.
7. Trained Logistic Regression and KNN models.
8. Evaluated and compared both models.

Model Results

Model| Accuracy
Logistic Regression| 93.33%
KNN| 93.33%

Conclusion

Both Logistic Regression and KNN achieved 93.33% accuracy on the test dataset. This project helped me understand data analysis, visualization, machine learning classification, and model evaluation.
